# Commercial license grant — template

A practical template for granting an individual commercial license for AgencyLaunch Kit. It is completed per licensee: fields in `[BRACKETS]` are placeholders for negotiated terms and must be filled in before use.

**This template is not a completed agreement and not legal advice.** It requires appropriate review before use. Do not publish or send a copy of this file with real buyer details, prices, or signatures inside the public repository — completed grants are private records.
